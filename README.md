# 🔐 Auth System (Node.js)

A secure and modern authentication system built using Node.js and Express.  
This project provides user registration, login, and advanced security features like JWT authentication and 2FA.

---

## 🚀 Features

- ✅ User Registration
- 🔑 User Login
- 🔒 Password Hashing (bcrypt)
- 🪪 JWT Authentication
- 🔐 Two-Factor Authentication (2FA) باستخدام QR Code
- 🌐 REST API (Express)
- 🗄️ Database using SQLite + Sequelize

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- SQLite3
- Sequelize ORM
- bcryptjs
- jsonwebtoken
- speakeasy (2FA)
- qrcode
- dotenv
- cors
